下面给出一个 **C++17 回调框架设计方案**，满足你的要求：

* ✅ 支持同步 / 异步操作
* ✅ 支持多级回调链
* ✅ 每个环节可同步或异步
* ✅ 基于串行队列（sequence queue）实现链式处理
* ✅ 结构清晰，可扩展

# 一、设计思路

我们实现一个：

```
Task -> Step1 -> Step2 -> Step3 -> ...
```

每个 Step：

* 可以同步执行
* 可以异步执行
* 必须在完成后触发“继续执行下一个 Step”

核心思想：

> 每个步骤都接受一个 `next()` 回调，调用它表示“我完成了”。

这样就可以把同步和异步统一起来。

# 二、核心组件设计

## 1️⃣ 串行执行队列（SequenceExecutor）

保证任务顺序执行。

```cpp
#include <functional>
#include <queue>
#include <thread>
#include <mutex>
#include <condition_variable>
#include <atomic>

class SequenceExecutor {
public:
    SequenceExecutor() : stop_(false) {
        worker_ = std::thread([this]() {
            run();
        });
    }

    ~SequenceExecutor() {
        {
            std::unique_lock<std::mutex> lock(mutex_);
            stop_ = true;
        }
        cv_.notify_all();
        worker_.join();
    }

    void post(std::function<void()> task) {
        {
            std::unique_lock<std::mutex> lock(mutex_);
            tasks_.push(std::move(task));
        }
        cv_.notify_one();
    }

private:
    void run() {
        while (true) {
            std::function<void()> task;

            {
                std::unique_lock<std::mutex> lock(mutex_);
                cv_.wait(lock, [this] {
                    return stop_ || !tasks_.empty();
                });

                if (stop_ && tasks_.empty())
                    return;

                task = std::move(tasks_.front());
                tasks_.pop();
            }

            task();
        }
    }

    std::queue<std::function<void()>> tasks_;
    std::mutex mutex_;
    std::condition_variable cv_;
    std::thread worker_;
    bool stop_;
};
```

## 2️⃣ 链式回调框架

核心思想：

```
每个 Step 形式：
void step(std::function<void()> next)
```

完成时调用 `next()`

---

### 定义 Step 类型

```cpp
using Step = std::function<void(std::function<void()>)>;
```

---

## 3️⃣ CallbackChain 类

```cpp
#include <vector>
#include <memory>

class CallbackChain : public std::enable_shared_from_this<CallbackChain> {
public:
    explicit CallbackChain(SequenceExecutor& executor)
        : executor_(executor), index_(0) {}

    void addStep(Step step) {
        steps_.push_back(std::move(step));
    }

    void start() {
        executor_.post([self = shared_from_this()] {
            self->runNext();
        });
    }

private:
    void runNext() {
        if (index_ >= steps_.size())
            return;

        auto step = steps_[index_++];
        step([self = shared_from_this()] {
            self->executor_.post([self] {
                self->runNext();
            });
        });
    }

    SequenceExecutor& executor_;
    std::vector<Step> steps_;
    size_t index_;
};
```

# 三、使用示例

## 示例 1：同步 + 异步混合

```cpp
#include <iostream>
#include <chrono>

int main() {
    SequenceExecutor executor;

    auto chain = std::make_shared<CallbackChain>(executor);

    // 同步步骤
    chain->addStep([](auto next) {
        std::cout << "Step1 (sync)\n";
        next();
    });

    // 异步步骤
    chain->addStep([](auto next) {
        std::cout << "Step2 (async begin)\n";

        std::thread([next] {
            std::this_thread::sleep_for(std::chrono::seconds(1));
            std::cout << "Step2 (async end)\n";
            next();
        }).detach();
    });

    // 同步步骤
    chain->addStep([](auto next) {
        std::cout << "Step3 (sync)\n";
        next();
    });

    chain->start();

    std::this_thread::sleep_for(std::chrono::seconds(3));
}
```

---

# 输出：

```
Step1 (sync)
Step2 (async begin)
Step2 (async end)
Step3 (sync)
```

保证顺序执行。

# 正确设计思路

我们要实现：

```cpp
chain
    .then(step1)   // A -> B
    .then(step2)   // B -> C
    .then(step3);  // C -> D
```

每一步：

* 接收上一步输出
* 返回下一步输出
* 可以是同步或异步
* RPC 回调完成时才继续

# 核心思想：Continuation + 类型传播

我们定义一个泛型 AsyncChain<T>

---

# 一、核心实现（支持 RPC 异步）

## 1️⃣ 基础定义

```cpp
template<typename T>
class AsyncChain;
```

---

## 2️⃣ 内部状态

```cpp
template<typename T>
class AsyncChain : public std::enable_shared_from_this<AsyncChain<T>> {
public:
    using Callback = std::function<void(T)>;

    explicit AsyncChain(SequenceExecutor& executor)
        : executor_(executor) {}

    void start(T value) {
        executor_.post([self = this->shared_from_this(), value] {
            self->invoke(value);
        });
    }

    template<typename F>
    auto then(F&& func) {
        using NextType = typename function_traits<F>::return_type;

        auto nextChain = std::make_shared<AsyncChain<NextType>>(executor_);

        callback_ = [func = std::forward<F>(func), nextChain]
                    (T value) mutable {

            func(value, [nextChain](NextType nextValue) {
                nextChain->start(nextValue);
            });
        };

        return nextChain;
    }

private:
    void invoke(T value) {
        if (callback_)
            callback_(value);
    }

    SequenceExecutor& executor_;
    Callback callback_;
};
```

（简化了 function_traits，可用 std::invoke_result_t 替代）

# 二、定义 Step 形式

每个 step 统一为：

```cpp
void step(Input in, std::function<void(Output)> done);
```

同步：

```cpp
void step(int in, std::function<void(int)> done) {
    done(in + 1);
}
```

异步 RPC：

```cpp
void step(int in, std::function<void(std::string)> done) {
    service.rpcCall(in, [done](std::string result) {
        done(result);  // RPC 完成后触发
    });
}
```

# 三、使用示例（符合你场景）

```cpp
SequenceExecutor executor;

auto chain = std::make_shared<AsyncChain<int>>(executor);

auto c2 = chain->then(
    [](int input, auto done) {
        std::cout << "Step1 input=" << input << "\n";
        done(input + 10);
    });

    [](int input, auto done) {
        std::cout << "Step2 RPC call...\n";

            done(std::to_string(input));

        std::cout << "Final result = " << s << "\n";
        done(0);
    });

chain->start(5);
```

# 四、为什么这才是正确架构？

你现在的需求具备几个特征：

| 特征   | 说明            |
| ---- | ------------- |
| 类型变化 | 每一步输入输出不同     |
| 异步触发 | RPC 回调完成才继续   |
| 顺序保证 | 必须串行执行        |
| 结果传递 | 上一步输出 → 下一步输入 |

固定 Context 是不合适的。

正确模型是：

> Promise / Future / Continuation 模型
