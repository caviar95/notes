# 三、初始化场景（同步）

目标：

```text
sync 返回时 FSM 必须稳定
```

所以逻辑是：

```text
target
   ↓
openSwitch（等待）
   ↓
validate（等待）
   ↓
成功 → 进入 target
失败 → 进入 Undefined
   ↓
closeSwitch（异步）
```

对应代码逻辑（流程型思维）：

```cpp
void handleValidate(State target, Mode mode)
{
    if (mode == Init)
    {
        bool openOk = openSwitchSync();
        if (!openOk)
        {
            transit(Undefined);
            return;
        }

        bool valid = validateSync();

        closeSwitchAsync();   // 不影响状态

        if (!valid)
            transit(Undefined);
        else
            transit(target);

        return;
    }
```

特点：

✔ sync 阻塞等待
✔ FSM 最终状态确定


# 一、RPC 异步调用对主线程的影响是什么？

你现在的模型是：

```text
主线程(sync)
   ↓
service.openSwitch()
   ↓
RPC发出
   ↓
立即返回（不会阻塞）
   ↓
主线程继续运行
```

真正发生的事是：

👉 主线程完全不等待设备

RPC 的回调：

```text
未来某一时刻
   ↓
由 IO线程 / RPC线程 执行
   ↓
回调你的 lambda
```

也就是说：

| 阶段                   | 线程    |
| -------------------- | ----- |
| sync() 调用 openSwitch | 主线程   |
| RPC完成 → 回调触发         | RPC线程 |

所以：

> validate 回调 **不是在 sync 所在的时间线**

而是：

👉 来自未来

# 二、主线程会发生什么？

在 validate 还没回来时：

主线程可能：

✔ 又执行了一次 sync
✔ 状态已经变了
✔ 系统进入别的状态
✔ 甚至已经关闭流程

所以时间线可能是：

```text
T0: sync → target=Running → 进入 Validating → 发起 validate

T1: 主线程又 sync → target=Idle → 已切回 Idle

T2: validate 回调回来（成功）

如果不保护：
Idle → Running ❌（错误穿越）
```

这就是：

> 异步回调污染当前状态

# 七、校验处理核心

```cpp
void StateMachine::handleValidate(State target, SyncMode mode)
{
    // 每次校验创建新 token
    uint64_t token = ++validateToken_;

    if (mode == SyncMode::InitSync)
    {
        bool openOk = openSync();
        if (!openOk)
        {
            forceTransit(State::Undefined);
            return;
        }

        bool valid = validateSync();
        closeAsync();

        if (!valid)
            forceTransit(State::Undefined);
        else
            transit(target);

        return;
    }

    // Runtime async
    transit(State::Validating);
    startAsyncValidate(target, token);
}
```

```cpp
            return;
```

# 九、同步包装（Init使用）

## openSync

```cpp
bool StateMachine::openSync()
{
    std::mutex m;
    std::condition_variable cv;
    bool done = false;
    bool result = false;

    svc_.openSwitch([&](bool ok)
    {
        std::unique_lock<std::mutex> lk(m);
        result = ok;
        done = true;
        cv.notify_one();
    });

    std::unique_lock<std::mutex> lk(m);
    cv.wait(lk, [&]{ return done; });

    return result;
}
```

## validateSync

```cpp
bool StateMachine::validateSync()
{
    std::mutex m;
    std::condition_variable cv;
    bool done = false;
    bool result = false;

    svc_.validate([&](bool ok)

        std::unique_lock<std::mutex> lk(m);
        result = ok;
        done = true;
        cv.notify_one();
    });

    std::unique_lock<std::mutex> lk(m);
    cv.wait(lk, [&]{ return done; });

    return result;
}
```

# 四、发起校验流程

```cpp
void StateMachine::startAsyncValidate(State target, uint64_t token)
{
    transit(State::Validating);

    auto timeoutFlag = std::make_shared<std::atomic_bool>(false);

    {
        std::lock_guard<std::mutex> lk(timerMutex_);
        timeoutFlags_[token] = timeoutFlag;
    }

    startTimeoutTimer(token, timeoutFlag);

    svc_.openSwitch([this, target, token, timeoutFlag](bool ok)
    {
        if (!isTokenValid(token)) return;

        if (!ok)
        {
            cleanup(token);
            forceTransit(State::Undefined);
            return;
        }

        // 发送 validate 请求（无callback）
        svc_.sendValidateRequest(token);
    });
}
```

```cpp
void StateMachine::startTimeoutTimer(
    uint64_t token,
    std::shared_ptr<std::atomic_bool> flag)
{
    std::thread([this, token, flag]()
    {
        std::this_thread::sleep_for(std::chrono::seconds(5));

        if (flag->exchange(true))
            return; // 已被取消

        if (!isTokenValid(token))
```

```cpp
void StateMachine::cancelTimeout(uint64_t token)
{
    std::lock_guard<std::mutex> lk(timerMutex_);

    auto it = timeoutFlags_.find(token);
    if (it != timeoutFlags_.end())
    {
        it->second->store(true);
        timeoutFlags_.erase(it);
    }
}
```
